# 生日祝福网页

这是一个可以直接发送给朋友的静态生日网页。

页面现在是三段式礼物体验：

1. 生日快乐开场：蛋糕、礼花、星星和首屏照片。
2. 人物小宇宙：关键词、追星快乐角落和照片相册。
3. 祝福页面：生日祝福语、随机祝福按钮和结尾祝愿。

## 怎么打开

双击 `index.html` 就可以在浏览器里打开。发送给朋友时，请把整个 `friend-birthday-23` 文件夹一起压缩后发给她，她解压后双击 `index.html` 即可看到完整页面。

照片已经放在 `assets/photos` 文件夹里，发送时不要只发 `index.html`，要把整个文件夹一起发。

## 怎么改名字

打开 `birthday-profile.js`，可以修改她的名字、祝福语、关键词卡片、随机祝福、照片说明和落款。

其中“写给今天的你”这一页对应 `letter` 数组。你之后想到新的祝福语，只改 `letter` 里每一行引号中的文字即可。

页面不依赖网络，也不需要安装任何工具。
